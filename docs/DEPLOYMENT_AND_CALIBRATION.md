## 二、边缘硬件加速转换命令（TensorRT / RKNN / OpenVINO）

本仓库所有 `.onnx` 均为 **静态 `opset=12` + `onnxslim` 简化**，可直接对接主流车载推理引擎：

### 1. NVIDIA Jetson Orin Nano / NX（TensorRT FP16）
```bash
trtexec --onnx=stage1_v8n_v52_1024.onnx --saveEngine=stage1_v8n_v52_1024_fp16.engine --fp16
trtexec --onnx=stage2_v8n_v52_384.onnx  --saveEngine=stage2_v8n_v52_384_fp16.engine  --fp16
```

### 2. RK3588 / 香橙派 5（RKNN-Toolkit2 INT8，三核 NPU 并行）
- 使用 `rknn.config(mean_values=[[0,0,0]], std_values=[[255,255,255]], target_platform='rk3588')`
- 量化校准集建议提供 **50~100 张赛场真实蓝地图片**（Stage 1）与 **50 张真实棋子裁片**（Stage 2），可同时保证 INT8 精度与 30–50 FPS 帧率。

### 3. Intel N100 / x86 工控机（OpenVINO FP16）
```bash
ovc stage1_v8n_v52_1024.onnx --compress_to_fp16
ovc stage2_v8n_v52_384.onnx  --compress_to_fp16
```

## 三、67 mm 标准棋子测距与场地坐标标定指南

### 方案 A：1 分钟单目像素宽测距（不依赖安装倾角）
1. 固定摄像头分辨率（如 `1280×720`）与定焦镜头；
2. 将一枚标准 **67 mm** 棋子放在镜头正前方精确 **`50 cm`** 处，用 `infer_onnx_twostage.py` 读出框的**水平像素宽度 `w_0 = x2 - x1`**（⚠️ 务必用水平宽度而非高度，斜拍时高度会被透视压扁）；
3. 生成标定文件：
   ```bash
   python calibrate_camera.py --mode monocular --img-width 1280 --z0-cm 50 --w0-px 84 --piece-mm 67 --out calib.json
   ```

### 方案 B（实车最推荐）：地面单应性标定（直接输出毫米级 `(X, Y)` + 物理尺度反误报）
1. 在车前蓝地上量出 **4 个已知相对车头的真实坐标** `(X_mm, Y_mm)`，记下它们在画面里的像素坐标 `(u, v)`；
2. 生成复合标定文件（同时带单应性 `H` 与单目宽度常数 `K`，自动启用物理宽度一致性防误报）：
   ```bash
   python calibrate_camera.py --mode both --img-width 1280 \
     --z0-cm 50 --w0-px 84 \
     --points 380,620=-200,300 900,620=200,300 460,410=-250,800 820,410=250,800 \
     --out calib.json
   ```
3. 推理时加上 `--calib calib.json`，每个棋子会自动附带 `world_x_mm`、`world_y_mm`、`dist_cm` 与 `width_ratio`！

## 四、实车决策端 JSON 协议与 120 秒提速策略

开启 `--json-out preds.json` 后，输出结构可直接喂给路径规划 / STM32 串口协议：
```json
{
  "cars": [{"class": "smart_car", "conf": 0.87, "xyxy": [160, 180, 480, 420], "dist_cm": 68.4}],
  "pieces": [
    {
      "class": "black_rook",
      "zh": "白車",
      "conf": 0.91,
      "score_bucket": "black_5",
      "score_zh": "白5分",
      "score_pts": 5,
      "score_prob": 0.95,
      "xyxy": [232, 367, 288, 423],
      "world_x_mm": -45.2,
      "world_y_mm": 512.0,
      "dist_cm": 51.4
    }
  ],
  "red_score": 23,
  "black_score": 18
}
```

### 120 秒高速对抗策略建议
1. **分值优先目标选择**：利用 `score_pts / dist_cm`（单位距离分值密度）优先抢占 `10分（帥/將）` 与 `5分（車）`，其次 `3分（馬/炮）`；
2. **开启 `--temporal --fast-single-crop`**：视频流下已连续 4 帧高置信锁定的静止棋子自动复用缓存，Stage 2 算力开销下降 70%+；
3. **赛场新机位微调建议**：上真车后用板载相机在赛场光照下录 20 秒视频，抽 40 帧核对即可将实车域差压到最低。
